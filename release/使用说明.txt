影棋 · YehuStyleGo（Windows 64 位）

一、启动
1. 解压下载包，保持 YehuStyleGo.exe 和说明文件在同一个文件夹。
2. 双击 YehuStyleGo.exe，不需要安装 Python；也可以双击同目录的 `启动影棋.vbs`，不会闪出黑色命令行窗口。
3. 第一次打开会自动进入“设置”：填写你自己的野狐用户名，点“保存设置”。
4. 右上角可切换“夜间模式 / 日间模式”，选择会保存在本机，下次启动自动恢复。

二、获取自己的棋谱
1. 自己登录野狐官方 Windows 客户端。
2. 打开“棋谱欣赏 → 我的棋谱”，让列表按最新对局在前，并载入需要的历史记录。
3. 关闭已打开的历史复盘棋盘和保存对话框，保留“我的棋谱”列表。
4. 回到影棋，打开“棋谱库”，点“同步野狐棋谱”，核对后开始。
5. 同步只通过已登录客户端的本机历史界面保存 SGF；不收集密码、不自动登录、不操作在线棋局。
6. 默认上限 100 盘，可在“设置 → 同步/训练盘数上限”改为 100、300、500 或 1000。实际能同步多少盘以野狐列表已载入的盘数为准；1000 盘可能需要数小时，可随时取消，已完成部分会保留。

三、训练和对弈
- 同步完成后会自动去重导入，并用当前上限内的最近棋谱训练个人落子偏好。
- 到“模拟对弈”可以直接和轻量陪练对弈，不需要 KataGo。
- 对局结束后，在“模拟对弈 → 保存与状态”点 **“保存并复盘”**：棋谱会保存到数据目录的 local-games 文件夹，自动导入棋谱库并打开复盘。另一个“导出 SGF 文件…”按钮只导出到你选择的位置。
- 在复盘页点 **“更新棋风”**，会用当前棋谱库重新训练；只学习你本人落子，陪练落子只用于重现局面。
- 复盘页右上角的 **“分析这盘棋”** 可直接分析当前选中的棋谱；已分析过的对局会显示“重新分析”。
- 选中分析表中的一手会先标出首选；点击绿圈或 **“查看推荐变化”** 后会显示 KataGo 前排候选点（编号 1–5，1 为一选），圈内显示胜率，颜色按损失递增（绿=一选、青=接近、橙=小失、红=较大损失）。悬停编号可在棋盘上预览该候选的变化，右侧对应行同步高亮。
- 点击编号、按数字键 **1–5** 或点击右侧变化手顺中的任意一行进入变化；用 **← / →**、鼠标滚轮、**Home / End** 或下方按钮逐手查看，下一手以淡色棋子提示。红圈为实战落点、绿圈为所选候选。
- 进入变化后点 **“分析此变化”**，只对这条分支跑 KataGo；完成后列表显示每步本人胜率、目差和较上步升降（绿=对本人变好、橙=小降、红=明显变差）。结果缓存在内存中，不会改动整盘分析或棋力档案。按 **Esc** 或点 **“返回实战”** 恢复。推荐变化只用于复盘，不会写回棋谱。
- 想要真实分析、形势判断、引擎陪练和棋力匹配，需要自行配置 KataGo（见第四节）。
- 首次使用建议在“棋谱库”点“分析列表”，为棋力匹配建立你的实战损失档案。
- “棋力匹配”默认开启：强度 0.5 约等于你的实战损失水平；调高更接近引擎最佳着，调低允许更多失误。
- 试下 / 变化推演、形势判断、终局数子等按钮在“模拟对弈”右栏；右栏可滚动。

四、KataGo
- 如果解压后的完整包里有单独的“引擎”文件夹，并与“程序”文件夹同级，影棋会自动识别其中的 KataGo 1.18.1 OpenCL 和 b18c384 模型，一般不需要手动选择路径。
- 如果使用的是不含引擎的下载包，或自动识别失败，可从官方下载：
  引擎：https://github.com/lightvector/KataGo/releases
  模型：https://katagotraining.org/
- 在“设置”里选择 KataGo 程序和 .bin.gz 模型，保存后点“测试 KataGo”。
- 随包引擎是 OpenCL 构建，依赖显卡驱动；没有合适 GPU 时分析可能很慢或无法使用。首次加载和调优可能较慢。
- 未配置引擎时使用轻量陪练，不会伪造胜率或分析结果。
- 随包引擎和模型的许可文件见“引擎/LICENSE-KataGo.txt”和“引擎/LICENSE-Model.txt”；请保留这些声明。

五、联机对弈（可选）
- 联机账号独立于野狐。第一次使用需注册用户名和密码，服务器会生成一个 9 位数字 UID；UID 在同一个服务器内唯一，不同服务器账号体系独立。没有邮箱或密码找回功能，请记住密码。
- 房主联机：一个玩家进入“联机对弈”，点 **“本机开房（启动服务器）”**。程序会显示形如 192.168.1.5:8765 的地址；同一 Wi-Fi 的朋友在“服务器地址”填这个地址，注册/登录后输入房主分享的 6 位房间码。关闭影棋或点“停止本机服务器”后服务停止。公网联机需要端口映射或内网穿透。
- 中央服务器：在一台大家都能连到的电脑上运行 YehuStyleGoServer.exe，玩家在“服务器地址”填服务器 IP:端口。账号和 UID 保存在服务器上；服务器重启后账号保留，但未结束的房间会丢失。
- 对局支持 9/13/19 路、白贴 7.5 目、停一手、认输。落子由服务端校验；双方连续停一手后进入数子确认，双方都同意才结束，任一方可点“继续下棋”撤回最后两次停一手。首版不会自动标记死子，不认可结果时请继续把死子提掉。
- 安全提示：联机服务器是明文 TCP，没有内置 TLS。请只在可信局域网、VPN 或 SSH 隧道中使用，不要把端口直接暴露到公网；不要复用重要密码。房主启动服务器时 Windows 防火墙可能询问是否允许。

六、数据和隐私
- 棋谱、模型、分析缓存保存在：%LOCALAPPDATA%\YehuStyleGo
- 本地棋谱、模型和分析缓存只在本机。联机模式会把你注册/登录的账号和对局落子发送到你选择的联机服务器；密码由服务器保存为加盐哈希，客户端不保存密码。
- 不收集你的野狐密码、Cookie 或登录令牌；不读取野狐客户端内存、不注入、不拦截野狐登录或网络协议。
- 卸载时关闭程序，手动删除上面的数据目录即可。

七、常见问题
- Windows 提示“已保护你的电脑”：这是未签名程序的 SmartScreen 提示，可点“更多信息 → 仍要运行”。请只从你信任的人那里获取本程序。
- 同步时提示“保存按钮外观与已验证版本不一致”：野狐客户端版本、主题或缩放可能变化。程序会停止而不是猜测点击；请恢复客户端默认主题/缩放，或更新影棋。
- 同步前必须关闭已打开的历史复盘棋盘；同步期间不要操作野狐窗口。
- 分析或同步过久可点底部“取消任务”，已完成部分保留。
- 导入 SGF 失败时，弹窗会显示文件名和原因；完整错误记录在 `%LOCALAPPDATA%\YehuStyleGo\last-import.log`。支持 UTF-8、GB18030、Big5，以及带 BOM 的 UTF-16/UTF-32。
- 同步时如果提示“棋谱不包含本人姓名”或“跳过不含当前姓名的棋谱”：请确认“设置”中的野狐用户名与当前登录账号完全一致；程序会安全跳过不属于当前账号的记录，不会保存错人的棋谱。
- 本软件不是完整围棋 AI，不保证模仿准确率或段位；形势判断仅供参考，终局数子需要人工确认死子。

八、删除棋谱和交接电脑
- 在“棋谱库”可以多选棋谱，点 **“删除选中”** 删除选中的棋谱记录及分析缓存；点 **“清空棋谱”** 删除整个棋谱库及全部分析缓存，并关闭自动扫描、清除原棋谱文件夹设置，避免旧 SGF 在下次启动时被重新导入。
- 这两种操作都**不会删除原始 SGF 文件**；原始文件仍在数据目录和野狐导出目录中。
- 清空棋谱时会询问是否同时删除本机所有棋风模型和棋力档案。选择“是”后，下一位使用者填写自己的野狐用户名、重新同步或导入自己的棋谱，即可训练属于他的陪练。
- 清空后如果仍使用同一个 Windows 用户，建议在“设置”中把野狐用户名改成下一位使用者的名字，再导入他的棋谱。

九、名手棋风陪练
- 在“模拟对弈 → 对弈风格”可以选择“我的棋风”或已导入的名手模型。
- 点“导入名手…”，输入姓名并选择装有该名手 SGF 的文件夹。姓名必须与 SGF 的 PB 或 PW 完全一致；软件会筛选包含该姓名的棋谱并训练独立模型。
- 点“批量导入多个名手…”，可一次输入多个姓名（用逗号或顿号分隔），程序只读取一遍文件夹，再依次训练。训练在后台低优先级运行，可以继续使用电脑，底部可取消。
- 软件不会自动下载职业棋谱，也不附带真实职业棋手数据。请只导入你有权使用的 SGF；名手模型只保存在本机，不会随分享包分发。
- 名手模式默认使用 KataGo 候选着并按该名手偏好选点，默认强度 0.82，可用滑条调整；不会使用你的个人棋力损失档案。没有配置 KataGo 时只能做轻量近似，不代表真实职业棋力，也不代表棋手本人或官方授权。
- “删除当前名手模型”只删除本机模型，不删除原始 SGF。清空棋谱并选择同时清理棋风数据时，名手模型和索引也会一起删除。
